psPodTester is a PowerShell 7 module for testing container deployments.
- GitHub Project: github.com/seabopo/psPodTester/blob/v2.x/
- Docker Images: hub.docker.com/repository/docker/seabopo/pspodtester


Session Information


Container
View container debugging information and environment variables.
Add custom information by setting "PSPOD_INFO_CUSTOMNAME" environment variables.

Example: 

                env:
                - name: PSPOD_INFO_NODE_IP
                valueFrom:
                    fieldRef:
                    fieldPath: status.hostIP
                - name: PSPOD_INFO_POD_IP
                valueFrom:
                    fieldRef:
                    fieldPath: status.podIP
                - name: PSPOD_INFO_POD_NAME
                valueFrom:
                    fieldRef:
                    fieldPath: metadata.name

Request Information
View user request information.
- Clicking the button shows the request headers for this application.
- Send a GET or POST to /echo to view all of the properties.


Logs


Application
View the application console logs (startup, tests progress, etc.).


User Requests
View the user requests to the pod.
This shows both real user and healthz requests.


Message Service
If the message service is enabled this will show every automatically generated console test message.
The send rate and a custom log message can be configured via environment variables.


Tests


Tests must be enabled in the pod deployment configuration (they are disabled by default) and are only available to users whose IP addresses are in the defined admin CIDR.


Connectivity
View the application console logs (startup, tests progress, etc.).

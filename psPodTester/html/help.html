psPodTester is a PowerShell 7 module for testing and debugging container deployments.
- GitHub Project: github.com/seabopo/psPodTester/blob/v2.x/
- Docker Images: hub.docker.com/repository/docker/seabopo/pspodtester


Environment Information


Container Properties
View container and host debugging information and environment variables.
Add custom information by setting "PSPOD_INFO_CUSTOMNAME" environment variables.

Example: 

                env:
                - name: PSPOD_INFO_NODE_IP
                valueFrom:
                    fieldRef:
                    fieldPath: status.hostIP

HTTP Headers
View the request headers that make it to the container through CDN and other Cloud services.


Perform an ECHO Test
Send a GET or POST to /echo to view all properties of the request.


External Connectivity
See the results of a "www.cloudflare.com/cdn-cgi/trace" request from this container.
Use this to get the public/gateway IP used for traffic from this container or host.


Logs


Application
View the application console logs (startup, tests progress, etc.).


User Requests
View the user requests to the pod.
This shows both real user and healthz requests.


Message Service
If the message service is enabled this will show every automatically generated console test message.
The send rate and a custom log message can be configured via environment variables.
